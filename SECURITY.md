# Security policy

Only the latest published release receives security fixes. Older releases, including the historical 2.2.0 recovery, are unsupported.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/faraajs/tidy/security/advisories/new), not a public issue. Include the version, Android/API version, ABI, affected behavior and a minimal reproduction using synthetic images. Do not post private media, credentials, personal paths or unredacted device logs.

Retain independent backups and pause monitoring if a suspected issue could affect originals. Reports are reviewed by the maintainer; no response-time guarantee or claim of complete security coverage is made.
